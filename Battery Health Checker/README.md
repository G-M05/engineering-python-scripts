# Battery Health Checker

A small Python utility that evaluates battery voltage levels and determines whether a battery is operating within an acceptable range.

## Features

- User voltage input
- Voltage range checking
- Battery health output
- Simple command-line interface

## Concepts Practiced

- Functions
- Conditionals
- User input
- Engineering-oriented scripting

## Future Improvements

- Support for multiple battery chemistries
- Percentage estimation
- CSV logging
- Data visualization
